# Prosto releases

[Open Prosto Web](https://bsafronov.github.io/prosto-releases/).

This repository distributes compiled Prosto Web files, signed Android APKs and update metadata. Source code is maintained separately. Android candidate releases remain drafts until application acceptance is complete.

The Web app is published from the `gh-pages` branch. The `web-verified` tag marks the last distribution that passed live acceptance checks; Android update metadata remains on `main`.
